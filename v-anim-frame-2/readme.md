帧组件使用文档：

1. 把多张图片帧合成一张
   使用 https://www.toptal.com/developers/css/sprite-generator 合成，注意帧与帧之间边距改为0，从做左到右排列。
2. 把合成后图片放在云端（可以放在云开发云存储），得到合成后的网络地址。
3. 引用组件，并使用组件

组件属性：
url:合成后的外链
width:单张图片帧的宽度
height:单张图片帧的高度
count: 图片帧数量
duration:播放一帧的时间

注意事项：

1. 制作时，帧与帧编辑为 0，从左到右排列
2. url 必须为网络外链
